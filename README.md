# typecho-plugin-filemanager
Typecho的文件管理增强版插件，文件分类、批量整理、文件分析、文件分享的文件库，增加了图片格式转换、在线编辑文本、压缩解压、分享链接、对接图床/对象存储、编辑器集成等众多功能。

## 特点功能
### 文件管理
- 无限层级文件夹，支持嵌套
- 一键所有文件归类，支持文件类型、文章分类、年月分类
- 三种视图：网格式（4X7、5X6）、瀑布流、列表
- 批量操作文件：鼠标框选多个文件、Ctrl+A全选当前列表所有文件、鼠标拖拽文件批量移动
- 回收站：用于防误删，可恢复、可彻底清除、保留天数可配置
- 文件体检：查找重复文件、未登记文件、失效文件
- 存储统计：按类型、文件夹、后缀统计占用，列出最大的文件
- 搜索筛选：按文件名或URL搜索，按类型筛选、排序

### 图片处理
- 上传图片转换格式：WebP、JPG、PNG，可添加文字或图片水印，可调图像质量、透明度、水印添加位置
- EXIF查看：拍照参数、相机型号、拍摄时间（PHP需安装exif扩展）
- 旋转图片角度
- 图片缩略图缓存，文件列表时加载图片时自动为图片生成小尺寸缩略图，用于加速列表中的图片缩略图，可节省CDN流量

### 文本编辑器
- 文本、代码在线编辑：语法高亮、多主题、编码识别与转换

### 压缩和解压
- 在线压缩：多文件打包ZIP，也支持跨文件夹打包（不支持添加解压密码）
- 在线解压：解压到指定文件夹，带密码的压缩包也能解压

### 文件分享系统
- 自有独立的文件分享页，不依赖主题，分享页可添加顶部/底部广告位
- 可设置提取密码、有效期（永久、1 天、7 天、30 天）、下载次数上限
- 可设置自定义短链（如 /file/s/FileManager）
- 可设置仅登录用户可下载
- 自定义文件展示名称、文件备注，备注支持HTML（可填写解压密码、使用方法或注意事项等等）
- 记录分享链接的浏览次数、下载次数，下载计数真实（文件完整下载后次数 +1，中途取消下载不算次数）
- 图片、视频、音频、PDF、文本等文件类型可设置在线预览
- 防直链：下载链接随浏览会话，换浏览器即失效，不暴露文件真实路径

### 图床与对象存储
- 上传文件到兰空图床/S3对象存储，存量文件可批量迁移，可删本地原文件、可替换正文引用链接。

### 编辑器集成
- 替代原生附件管理
- 拖拽上传到面板、粘贴截图上传（Ctrl+V）
- 一键插入正文
- 图片链接悬浮预览
- 插入分享链接按钮：8 种形状、7 种配色

### 偏好设置
- 默认列表布局、默认排序、上传默认位置、快捷键、高亮主题、缩略图缓存等多个细节偏好设置让你用着得心应手。

### 插件下载地址
  [点此下载插件包](https://github.com/bufanblog/typecho-plugin-filemanager/releases/download/v1.0.0/FileManager_1.0.0.zip)

### 安装方法
  将压缩包中的 FileManager 文件夹上传到 `usr/plugins/` 目录，然后在后台启用插件。

### 使用须知
- 转换图片格式建议PHP安装ImageMagic扩展，可处理5000万~2亿像素的高像素图片
- 上传相机拍的照片需要显示EXIF（光圈、快门速度、ISO、设备型号等信息），PHP安装EXIF扩展
对JPG图片旋转无损保存，服务器终端需要jpegtran工具，在服务器终端执行 `apt install -y libjpeg-turbo-progs`
